# NEXOVONARSA WhatsApp Business Suite

## Scope
- Professional customer-service auto replies
- AI intent triage with human handoff
- Purchase and finance reporting
- Separate Excel and Word reports
- Google Drive canonical-file replacement strategy
- Admin approval workflow for groups
- WIB quiet-hours policy: 23:00 to 05:00
- Grey/blue web dashboard
- JavaScript, TypeScript, Python, CSS, SQL and optional C++

## Security
Sensitive identity documents and face media must remain in private encrypted storage. Do not commit such data to GitHub. Collect only necessary information after clear consent, with role-based access, retention limits and deletion controls.
